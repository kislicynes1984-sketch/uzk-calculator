«Затухание УЗК» — установка на iPhone как веб-приложение (PWA)

Приложение построено без сторонних библиотек, серверных расчётов и сетевых API.
Для установки на домашний экран iPhone нужно ОДИН раз открыть файлы на HTTPS-сайте:
  1. Поместить все файлы данного каталога на HTTPS-сервер с сохранением путей.
  2. На iPhone открыть ссылку в Safari.
  3. Нажать «Поделиться» -> «На экран Домой» -> «Добавить».
  4. Открыть значок приложения при наличии интернета один раз, чтобы файлы закешировались.
После этого калькулятор работает без интернета. Для проверки можно включить авиарежим.

ВАЖНО: скачивание ZIP на iPhone само по себе НЕ устанавливает PWA, потому что iOS требует открытие HTTPS-сайта в Safari. Если требуется установить полностью нативное iOS-приложение, есть отдельный проект Xcode.

Возможность использования без размещения на сайте: отдельный файл
«Калькулятор_затухания_УЗК_офлайн.html» содержит весь код и вычисления без интернет-соединения. В зависимости от приложения «Файлы»/браузера на iPhone может потребоваться открыть его в Safari.

Состав:
- Прямой ПЭП 0°, варианты 1/2 и 3/4 донных эхосигналов.
- Наклонный ПЭП 45–70°, измерение по двугранному углу; ручной ввод пути по умолчанию.
- Режим неизменного усиления: разность A1-A2.
- Режим «одинаковая высота»: G2-G1, где G — значения усиления дефектоскопа, НЕ высота сигнала в процентах.
- Результат в дБ/м; оценочная составляющая поправки переноса чувствительности по разности затухания между изделием и СОП.

Основа: файл «Ультразвуковой контроль.xlsx» пользователя; 3 блока расчётов и их формулы сохранены.
Ограничения: поправка по закону 20lg(S2/S1) приближённая, дополнительные потери не измеряются; по двугранному углу для 55–70° необходима проверка применимости метода и коррекции, результаты не заменяют утверждённую методику.


Обновление v1.1: верхний блок (шапка + заголовок + переключение вкладок) закреплён на экране, прокручивается только остальное содержимое.

Вариант B: закреплены компактная шапка и вкладки.

ИТОГОВЫЙ ДИЗАЙН: вариант Б. Сверху зафиксированы компактная шапка и вкладки ПЭП. Большой заголовок и содержимое прокручиваются.


v1.2: для наклонного ПЭП добавлен ввод ближней зоны N (мм), проверка L1 >= 3N и минимальной толщины t_min = 3N*cos(угол) для схемы L1=t/cos(угол). Результат коэффициента при несоблюдении критерия сохраняется только как предварительный, поправка усиления блокируется. В рамках ГОСТ Р 50.05.05-2018 А.3.1 метод по двугранному углу предусмотрен для 45–52°, а для 53–70° требуется иное обоснование.


v1.3: ближняя зона наклонного ПЭП вычисляется по введенным частоте, размерам пьезоэлемента, скоростям в металле и призме и пути ультразвука в призме. Предусмотрены круглые и прямоугольные элементы (коэффициент формы по таблице Olympus). Состояние проверки L1 ≥ 3N рассчитывается автоматически.


v1.4: расчёт N по ГОСТ Р 50.05.05-2018 п. 7.1.12 (S*f*cos(alpha)/(pi*ct*cos(beta))), без пути в призме. По старой модели результаты N могли существенно отличаться.


v1.5: уточнены обозначения углов: α — угол ввода в металл, β — угол в призме, определяемый через скорости и α по закону Снеллиуса. Формула ГОСТ: N = S*f*cos(α)/(π*c_t*cos(β)); t_min=3N*cos(α). Путь в призме не вводится. Контрольный пример: D=12 мм, f=2,5 МГц, α=50°, c_t=3230 м/с, c_p=2700 м/с -> β≈39,82°, N≈23,32 мм, t_min≈44,97 мм.


v1.6: угол β и cos β по Снеллиусу вычисляются автоматически; скорость продольной волны в оргстекле (2700 м/с) закреплена как типовая константа. Поле скорости призмы удалено. Скорость поперечной волны в металле остаётся редактируемой.

Обновление v1.7: вкладка прямого ПЭП получила автоматический расчёт ближней зоны по f, размеру пьезоэлемента и скорости продольной волны; проверку t ≥ 3N; предупреждения и блокировку поправки при недостоверных условиях. Для прямоугольной пьезопластины — приближённая оценка по площади.

Обновление v1.8: подробная инструкция для прямого и наклонного ПЭП в раскрывающемся разделе «Формулы и объяснения · инструкция»: подготовка, отбор сигналов, ближняя зона, ввод уровней, перенос с СОП и нормативные ограничения.
