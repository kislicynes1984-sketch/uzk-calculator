# Затухание УЗК — PWA для iPhone

Статический калькулятор для прямого и наклонного ПЭП. Отдельный сервер или App Store не нужны.

## Размещение через GitHub Pages

1. Создайте **отдельный публичный** репозиторий `uzk-calculator` с веткой `main`.
2. Загрузите в корень репозитория файлы этого пакета, сохранив вложенные каталоги `assets/` и `.github/workflows/`.
3. В GitHub откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. В разделе **Actions** дождитесь завершения действия **Publish UZK PWA to GitHub Pages**. При необходимости выполните **Run workflow**.
5. Откройте опубликованный HTTPS-адрес в Safari на iPhone и выберите **Поделиться → На экран «Домой»**.
6. После первого открытия PWA кэширует файлы и работает без сети. Для обновления нужно открыть сайт при наличии интернета.

Файлы можно загрузить через подключённый GitHub после создания репозитория. Репозиторий `family-menu` не используется.
